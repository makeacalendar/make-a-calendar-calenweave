# Make a Calendar feature map

This guide records public pages inspected on 2026-10-12 and the nearest
CalenWeave feature. It describes observed workflows, not private APIs.
CalenWeave is an independent implementation; the reference site includes
presentation, holiday, and browser features that this SDK does not reproduce.

| Verified page                                                                                                                                                                            | User problem and observed workflow                                                                                  | CalenWeave API                                                                                                             | Scope and edge cases                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Monthly calendars](https://make-a-calendar.com/monthly-calendars)                                                                                                                       | Browse twelve months, change Sunday/Monday week start, toggle US holiday marks, add notes, print or share a month.  | `core.createMonthGrid`, `rendering.renderCalendarSVG`, `rendering.renderCalendarHTML`, `rendering.renderCalendarPrintHTML` | The SDK generates date grids and self-contained markup. It does not include an editor, holiday labels, notes UI, PDF engine, or share links. Grid rows vary from four to six weeks unless the caller requests a six-row view.                      |
| [2027 yearly calendar](https://make-a-calendar.com/yearly-calendars/2027)                                                                                                                | Read all twelve months in one year view, with week numbers and holiday marks.                                       | `core.createYearGrid`, `core.isoWeek`                                                                                      | Year grid math is implemented. This SDK does not add week-number columns or holiday decoration to the year grid. ISO week-year can differ from the civil year around New Year.                                                                     |
| [Blank calendar templates](https://make-a-calendar.com/pages/blank-calendar)                                                                                                             | Print an undated calendar template and fill dates or plans by hand.                                                 | No direct API; date-backed grids are available from `core.createMonthGrid`.                                                | A genuinely undated empty template is not implemented. A dated grid with blank event cells is not the same artifact.                                                                                                                               |
| [Custom calendar generator](https://make-a-calendar.com/calendar-generator)                                                                                                              | Build a January–December year grid with a selectable week start.                                                    | `core.createYearGrid(year, weekStartsOn)`                                                                                  | Pure civil-year layout; leap day follows the year being generated. No browser form or PDF exporter is included.                                                                                                                                    |
| [Multi-month calendar](https://make-a-calendar.com/multi-month-calendar)                                                                                                                 | Show a chosen count of consecutive months starting in any month, including across December.                         | `core.createMonthSpan(startYear, startMonth, count, weekStartsOn)`                                                         | The reference page permits 2–18 months; the SDK permits 1–120. Each February uses its own year’s leap status.                                                                                                                                      |
| [Business days calculator](https://make-a-calendar.com/business-days-calculator)                                                                                                         | Count working dates in a range or move forward/back by workdays, optionally excluding US observed federal holidays. | `business.countBusinessDays`, `business.addBusinessDays`                                                                   | Weekends, closures and endpoint inclusion are configurable. Company, state and non-US holiday calendars must be supplied by the caller.                                                                                                            |
| [Workday calendar](https://make-a-calendar.com/workday-calendar)                                                                                                                         | Highlight Monday–Friday across a year, optionally removing US observed federal holidays.                            | `business.isBusinessDay`, `business.countBusinessDays`; render one month with `rendering`                                  | The reference produces an annotated year grid. CalenWeave offers predicates and month renderers, but no ready-made workday-year visualization or holiday-colored cells.                                                                            |
| [Pay period calendar](https://make-a-calendar.com/pay-period-calendar)                                                                                                                   | See weekly, biweekly, semi-monthly or monthly nominal pay dates across a year.                                      | `payroll.generateWeeklySchedule`, `payroll.generateSemiMonthlySchedule`, `payroll.generateMonthlySchedule`                 | A 14-day cadence is not the same as two fixed days per month. Payday adjustments preserve the nominal date in output; employers must choose their own closure policy.                                                                              |
| [Biweekly calendar](https://make-a-calendar.com/biweekly-calendar)                                                                                                                       | Continue a 14-day chain from a known occurrence through a calendar year.                                            | `payroll.generateWeeklySchedule(anchor, start, end, 2)`                                                                    | The anchor controls the cycle phase; weekends and holidays do not pause the chain. This is not a semi-monthly schedule.                                                                                                                            |
| [Rotating shift calendar](https://make-a-calendar.com/shift-calendar)                                                                                                                    | Paint on/off dates from a start phase for common 4–3, 5–2 and 2–2–3 rotations.                                      | `shifts.shiftPatterns`, `shifts.generateShiftRotation`                                                                     | Cycles continue across month boundaries and leap day. The SDK does not compute labor law, shift hours, overtime or multi-person coverage.                                                                                                          |
| [Net 30 calculator](https://make-a-calendar.com/net-30-calculator)                                                                                                                       | Add calendar or business days to an agreed invoice anchor and review month-end terms.                               | `business.calculatePaymentDeadline`, `business.calculateNet30`                                                             | Anchor date, day type, endpoint inclusion, month-end, and adjustment are explicit options. Contract wording determines the correct anchor and weekend/holiday policy.                                                                              |
| [Deadline calculator](https://make-a-calendar.com/deadline-calculator)                                                                                                                   | Work backward from a due date by a calendar-day lead time.                                                          | `core.addDays` with a negative count; business-day movement via `business.addBusinessDays`                                 | The reference is a simple reverse calendar-day calculation. Inclusive legal deadline rules and court closures require caller policy.                                                                                                               |
| [4-4-5 retail calendar](https://make-a-calendar.com/445-calendar)                                                                                                                        | Build 12 retail periods in 4/4/5 week groups from the Sunday nearest February 1.                                    | `fiscal.createRetailFiscalYear(label, "4-4-5")`                                                                            | CalenWeave also accepts 4-5-4 and 5-4-4. It is a planning model, not a licensed NRF table; callers must decide the extra-week posting rule for a 53-week year.                                                                                     |
| [4-5-4 retail calendar](https://make-a-calendar.com/454-calendar)                                                                                                                        | Put the five-week period in the middle of each retail quarter.                                                      | `fiscal.createRetailFiscalYear(label, "4-5-4")`                                                                            | Pattern name must be explicit; the period containing five weeks changes. Retail weeks start Sunday and are not ISO weeks.                                                                                                                          |
| [5-4-4 retail calendar](https://make-a-calendar.com/544-calendar)                                                                                                                        | Put the five-week period at the start of each retail quarter.                                                       | `fiscal.createRetailFiscalYear(label, "5-4-4")`                                                                            | The SDK shares the fiscal-year boundary rule but not official NRF numbering or accounting policy. Confirm 53rd-week assignment against the system of record.                                                                                       |
| [Recurring dates](https://make-a-calendar.com/recurring-dates)                                                                                                                           | List bounded repeated calendar dates from a start, interval or weekday rule.                                        | `recurrence.iterateRecurrence`, `recurrence.nthWeekdayOfMonth`                                                             | The SDK supports bounded daily, weekly and monthly rules. Month-day overflow is clamped; it is not a full RFC 5545 recurrence engine.                                                                                                              |
| [Cron calculator](https://make-a-calendar.com/cron-calculator) and [cron calendar](https://make-a-calendar.com/cron-calendar)                                                            | Parse five-field crontab rules, preview next fires and visualize matching UTC dates for a selected month.           | `cron.parseCron`, `cron.nextCronRuns`, `cron.matchesCron`                                                                  | Numeric lists, ranges and steps use classic day-of-month/day-of-week OR behavior. No timezone database, daylight-saving simulation, seconds field, aliases, Quartz or AWS extensions.                                                              |
| [Date converters](https://make-a-calendar.com/converters), [Excel serials](https://make-a-calendar.com/excel-date-converter), [FILETIME](https://make-a-calendar.com/filetime-converter) | Convert date strings, spreadsheet serials, Unix milliseconds and Windows ticks with their own epochs.               | `converters` exports                                                                                                       | Excel 1900 serial 60 is a nonexistent date and is rejected by default; FILETIME is BigInt input in 100-nanosecond units; Unix API is milliseconds and discards time-of-day when returning `CivilDate`. No local-time zone conversion is performed. |
| [Julian Day Number](https://make-a-calendar.com/julian-day-number) and [Julian calendar](https://make-a-calendar.com/julian-calendar)                                                    | Distinguish astronomical day indexes and ordinal dates from civil Julian calendar labels.                           | `toJulianDayNumber`, `fromJulianDayNumber`, `civilDateToOrdinalDate`, `ordinalDateToCivilDate`                             | JDN functions map proleptic Gregorian civil dates to the conventional integer for the date. The SDK does not convert historical Julian calendar dates or calendar reforms. “Julian” can mean different systems.                                    |
| [iCalendar generator](https://make-a-calendar.com/ical-generator)                                                                                                                        | Export calendar events into a portable calendar file.                                                               | `exports.generateICS`                                                                                                      | Current API serializes date-only events. Recurrence properties, timed events, time zones, alarms and attendee workflows are not implemented.                                                                                                       |
